# Deep Learning Projects

A collection of my deep learning and neural network projects built while learning and experimenting with AI/ML concepts using Python, TensorFlow, Keras, and Streamlit.

This repository contains projects ranging from basic Artificial Neural Networks (ANNs) to Convolutional Neural Networks (CNNs), along with deployment experiments and practical applications.

---

# Projects Included

## 1. ANN Regression for bank churn

A basic Artificial Neural Network built for regression tasks to predict if the customer is likely to churn of not based on the given input paramters.

### Concepts Used
- Dense layers
- Forward propagation
- Backpropagation
- Loss functions
- Optimization
- Regression metrics

### Tech Stack
- Python
- TensorFlow / Keras
- NumPy
- Pandas
